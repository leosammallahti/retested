Methods

How Retested works

Everything here is generated from open data by a script, with source-checked additions kept in version control. Nothing is typed into a page by hand. This page explains the sources, the rules, and the limits.

Sources

Units

An attempt is one (original paper, replication paper) pair; we have 8,840 of them (8,560 replications, 280 reproductions). A finding is one original paper and all its attempts (6,829). An effect is a named phenomenon, such as "Ego depletion", which may span several original papers (2,125). An effect enters the database only once a replication of its own is linked; 177 more are named in FORRT's records without one and are listed apart. Where every FORRT row went is recorded file by file. Near-identical names that point at the same original paper are merged automatically only when they differ in spelling or word form; other names for the same effect are merged by a person who read both, with the reason recorded in data/curated/merges.yaml.

Original-study context

Finding pages use a priority fallback ladder for pre-guess context. Only 154 of 6,829 findings currently have a canonical, source-reviewed explanation of the original claim, method, population, and outcome measure. The remaining tiers are useful context, but not equivalent primary-source completion.

Context availableFindingsWhat it means
Canonical source-reviewed explanation154Original claim, method, population, and measure are each linked to reviewed primary-source evidence.
Plain-language game context442An answer-blind claim and experiment description already cleared the playable-card checks; this is not promoted to canonical source-reviewed status.
Reviewed-claim fallback1,540A Retested source review quotes the original claim, but the four-part explanation is not yet complete.
FORRT-coded-claim fallback260A claim is present in FORRT's coded row; it is not counted as a new source-reviewed explanation.
Named-effect fallback238An effect label supplies context where no claim field is available.
Title-only fallback4,088A paper title identifies the finding, but is not source-finished explanatory context.
No context field107No title, named effect, or claim field is currently available.

These are disjoint counts in rendering order, so each finding appears once. A title-only page is an addressable record, not evidence that its original study has been source reviewed.

Retested versus FORRT

The site and FORRT overlap, so “added to Retested” is not the same as “new to FORRT.” The evidence-first reconciliation registry compares every Retested-reviewed pair with commit-pinned or content-addressed FORRT snapshots. It currently supports 865 positive bibliographic same-pair relations, including 414 of Retested's 1,466 locally completed additions. Exact DOI identity is kept separate from reviewed preprint/journal-version identity.

A matching paper pair still does not prove the same effect, study, sample or outcome was assessed. Those four scientific axes remain unadjudicated, so the registry currently certifies 0 effects or replications as absent from FORRT. The remaining unmatched rows are comparison work, not novelty claims. The coverage and overlap page shows the complete partition, frozen corpus size, progress and assurance blockers directly from the validated build output.

Three lenses, never one score

1. What the replicators said. Each attempt's verdict comes from FLoRA, then FReD, then the legacy file, then Retested-reviewed primary papers. Rolled up with explicit rules over k, the number of attempts with a verdict:

LabelRule
Replicatedk ≥ 2, every attempt with a verdict succeeded
Largely replicatedk ≥ 2, (successes + ½ mixed) / k ≥ 75%
Contestedk ≥ 2, neither side reaches 75%
Largely failedk ≥ 2, (failures + ½ mixed) / k ≥ 75%
Failed to replicatek ≥ 2, every attempt with a verdict failed
Replicated once / Failed once / Mixed (one attempt)k = 1: we say so instead of pretending one study settles it
Reversedcurated judgement only; never computed from signs, which are unreliable across coding schemes
No clear verdictattempts exist but none has a coded outcome
No linked attempts yeta named effect with no attempt linked in the counted record (not a claim that none exists)

2. What the numbers say. Where effect sizes are coded, both sides are converted to Pearson r (FORRT's conversions). Rows inside one replication paper (sites, sub-studies) are pooled first, then papers are pooled with a DerSimonian–Laird random-effects model on Fisher z, giving a pooled r, a 95% CI, a prediction interval when k ≥ 3, and the ratio to the original's r. We label the result "holds at similar size", "holds, but smaller", "near zero", "opposite direction" or "too imprecise to say". We also show FORRT's seven criteria, because they answer different questions:

  • Replication is significant, same direction
  • Original + replication pooled is significant
  • Original falls inside replication's 95% CI
  • Replication falls inside original's prediction interval
  • Original and replication statistically consistent
  • Consistent and jointly significant
  • Replication rules out a tiny effect (small telescopes)

When the authors' verdicts and the numbers point opposite ways, the page says so ("the lenses disagree") instead of choosing one.

3. How they were done. Preregistration, independence of the replication team (FORRT's author-overlap coding), closeness to the original's materials and procedure (legacy coding), and whether an attempt was a replication (new data) or a reproduction (same data, re-analysed). These are shown, not scored.

The game

The game is a black, phone-style feed with one card per original study (not per effect row, so a 36-lab project does not become 36 identical cards), using only studies whose replication verdict is clear and consistent. Claims that mention replication, failure or robustness are removed. You tap Replicated or Didn’t; the answer is stored separately and fetched only after you tap. The feed keeps one number, how many of your calls were right, and it stays in this browser. Where a data source’s quote is only its own coding note (for example “Coded as not replicated: Replicate = 0”), the feed leaves it out and the full record shows it. The deck currently holds 1,394 study cards and 187 famous-effect cards.

Separately, every one of the 6,829 original-paper finding pages offers a four-way prediction before its source and attempt record. That page-level prompt includes mixed, unclear, and no-linked-attempt answers and does not add to the feed’s tally. It is a visual guess-before-reveal interaction on a static page, not a security boundary: someone can still inspect the downloaded page source.

Limits you should know

  • Selection. Replicated studies are not a random sample of psychology. Rates here describe what people chose to test.
  • Coverage. Most effects have one attempt. We label single attempts as such.
  • Coding. Verdicts are the replicators' own, coded by FORRT or checked against the primary paper for Retested-reviewed pairs. Sources sometimes disagree; we flag it.
  • Names. Effect names come from several lists and are imperfect. Every effect keeps a stable ID, so fixing a name never breaks a link.
  • Our unverified finds. Candidate papers are machine-screened and change no verdict, tally or figure. The build derives its audit figures from committed hand-read labels rather than prose typed into this page. Among the page-eligible original links read so far, 106 of 107 pointed to the intended original. Among candidate outcome labels read so far, 25 of 29 agreed with the source review. Those are sample results, not guarantees for unread rows. The rest wait in the queue for source review.
